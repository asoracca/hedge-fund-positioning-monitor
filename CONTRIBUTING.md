# Contributing

Install `pip install -e '.[dev]'`. Run `ruff check .`, `pytest -q`, and
`python scripts/execute_notebook.py` before opening a pull request.

Changes to timing, amendment semantics, signals or costs need an explanation and
a financial counterexample test. Retain source accessions and information dates.
Do not commit secrets or third-party data without redistribution rights. Label
demo results clearly and document limitations rather than implying validation.
