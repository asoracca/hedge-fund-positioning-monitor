# Third-party software

`assets/plotly.min.js` is the Plotly.js distribution bundled with Plotly Python
6.9.0. Its upstream copyright/license notice is retained in the file header.
The distribution's license is included in `assets/PLOTLY_LICENSE.txt`.
Source: https://github.com/plotly/plotly.js

All research observations in `assets/research.json` are generated by this
repository's seeded demo and Python research engine. They are not vendor data.
